# 剪辑工作台界面布局规范 (Edit Layout Specification)

本文档依据实测 Adobe Premiere Pro 经典四区分屏工作区（参考原图见 [docs/assets/pr-reference.png](file:///d:/Work/Dev/ClipFlow/docs/assets/pr-reference.png)），针对 ClipFlow **“Rust 1.98 + wgpu 30.0 + egui 0.36”** 技术底座、**“Windows 11 默认圆角”** 及 **“NVIDIA 信号绿 (#76B900)”** 设计体系制定的剪辑页面布局标准。

## 2. 六大功能区块深度规格

### 2.1 源监视器 (Source Monitor) [左上区域]
- **面板职责**：单素材独立预览、原始音视频属性核验、入点与出点快速粗剪。
- **顶部 Tab 栏**：
  - `Source: [素材文件名]`（主标签，支持关闭与多素材切换）
  - `Lumetri Scopes`（示波器标签）
  - `Audio Clip Mixer`（单素材音频混音器）
- **核心工作视窗**：
  - 由 `wgpu 30.0` 驱动的硬件纹理渲染视口，外框采用 Win 11 `8px` 圆角。
- **底部走带与控制栏（高度 36px）**：
  - **左侧时间码**：当前素材播放头时间（大字号等宽，`00:00:00:00`）。
  - **缩放与画质下拉框**：
    - 缩放模式：`Fit` (自适应)、`10%`、`25%`、`50%`、`100%`、`200%`。
    - 预览画质：`Full` (全分辨率)、`1/2`、`1/4`（快速解码，减轻 GPU 负载）。
  - **右侧时长**：素材总时长（`00:04:47:15`）。
  - **交互按钮序列（自左向右）**：
    - `Mark In` (标记入点 `{` / `I`)
    - `Mark Out` (标记出点 `}` / `O`)
    - `Go to In` (跳转至入点 `Shift + I`)
    - `Step Back 1 Frame` (后退一帧 `←`)
    - `Play / Stop` (播放/暂停 空格键)
    - `Step Forward 1 Frame` (前进一帧 `→`)
    - `Go to Out` (跳转至出点 `Shift + O`)
    - `Export Frame` (相机图标，当前帧截屏为静止图片)

---

### 2.2 节目监视器 (Program Monitor) [中上区域]
- **面板职责**：全局公用时间线当前合成画面的即时主监视器（反映 V 轨素材 + HyperFrames 动效层 + C 轨字幕的实时叠合效果）。
- **顶部 Tab 栏**：`Program: 主`（显示当前激活的时间轴序列名称）。
- **核心工作视窗**：
  - 呈现画面由 FFmpeg 9.0.2 / wgpu 多层着色器实时合成，支持直接在画面上双击进行画面位置拖动与变换手柄操作。
- **底部走带与控制栏**：
  - **当前时间码**：与全局公用时间线当前播放指针严格同步（`00:00:00:00`）。
  - **序列总时长**：整条时间线的最后剪辑点时间（如 `00:15:27:22`）。
  - **控制按键与切换开关**：
    - `Safe Margins` (动作与字幕安全框切换开关)
    - `Comparison View` (分屏比对视图，用于色彩匹配)
    - `Mark In` / `Mark Out` (设置时间线全局渲染入出点)
    - 逐帧步进、播放/暂停、快进快退。

### 2.3 多功能侧边辅助面板 (Inspector & Effects) [右上区域]
- **面板职责**：全局资产属性检查、转场与效果库检索。
- **顶部 Tab 导航**：
  - `Properties` (通用属性)
  - `Info` (元数据信息)
  - `Effects` (效果浏览器，默认展示)
  - `Graphics Templates` (动态图形模板)
  - `Essential Sound` (基本声音)
- **Effects 面板内部分级树**：
  - 顶部快速过滤搜索输入框（Win 11 `4px` 圆角，带清除按钮）。
  - 折叠树分类（每类带文件夹图标与数量统计）：
    - `> Presets` (系统预设)
    - `> Lumetri Presets` (调色滤镜 LUT 预设)
    - `> Audio Effects` (音频降噪、均衡、动态处理)
    - `> Audio Transitions` (交叉渐变恒定功率/增益)
    - `> Video Effects` (变换、裁剪、锐化、调色)
    - `> Video Transitions` (叠化、划像、缩放)
    - `> HyperFrames Templates` (⭐ **ClipFlow 特色**：代码动效角标与图表模板库)

### 2.4 项目素材池与效果控件面板 (Project Panel / Effect Controls) [左上区域 (宽 25%)]
- **面板职责**：工程素材管理、文件夹 Bin 分类、导入素材试看，并以 Tab 标签页整合【效果控件 (Effect Controls)】。
- **顶部 Bin 标签横向滑动页**：
  - `Bin: 70年代加油站`、`Bin: BGM`、`Bin: 口播音频`、`Bin: 30年代油井`、`Tab: 效果控件`
  - 点击支持在当前面板内钻取（Drill-down）或打开独立浮动窗口。
- **面包屑与搜索栏**：
  - 面包屑：`002 中东#1.prproj \ footage \ 70年代加油站`
  - 搜索框与选择统计标签：`1 of 8 items selected`。
- **双视图模式**：
  1. **网格图标视图 (Grid View)**：
     - 卡片圆角 `4px`，带素材首帧高清缩略图，悬停时支持鼠标左右刮擦 (Hover Scrub) 动态取帧预览。
     - 底部显示文件名及素材长度胶囊徽章（如 `4:47:15`、`2:01`）。
     - 选中项外框呈现 `1.5px solid #76B900` (NVIDIA 信号绿)。
  2. **列表视图 (List View)**：
     - 详细表格列：帧率 (fps)、入出点时长、音视频编解码器、分辨率。
- **底部工具栏**：
  - 视图切换按钮（网格 / 列表）、自由变换视图、新建素材箱 (New Bin 图标)、新建序列项、删除垃圾桶。

### 2.5 核心多轨公用时间线与工具条 (Multi-Track Timeline & Tools) [下半区 100% 满宽常驻]

#### 2.5.1 竖向精细工具条 (Tools Bar) 与快捷键系统
- **宽度**：`32px`，竖排紧贴在时间轴左侧。
- **核心工具清单与单键映射**：
  - `选择工具 (Selection Tool)`：`V`（默认鼠标指针，支持范围选区与单选）
  - `向后选择工具 (Track Select Forward)`：`A`（选中当前点击位置之后所有轨道的所有片段）
  - `波纹编辑工具 (Ripple Edit Tool)`：`B`（调整片段边缘时后续所有片段自动收缩或后移）
  - `剃刀工具 (Razor Tool)`：`C`（在鼠标悬停处即时切割音视频切片）
  - `滑动工具 (Slip Tool)`：`Y`
  - `钢笔工具 (Pen Tool)`：`P`（在音频轨或效果上打关键帧）
  - `抓手工具 (Hand Tool)`：`H`（平移时间轴视野）
  - `文字工具 (Type Tool)`：`T`（直接在监视器新建字幕文本）

#### 2.5.2 J-K-L 工业级飞梭走带状态机 (Shuttle Transport State Machine)
完全对齐 Premiere Pro 与 DaVinci Resolve 工业级剪辑师核心肌肉记忆：

| 按键组合 | 核心走带动作 | 状态机转移逻辑与速率 |
| :--- | :--- | :--- |
| **`L` (单按 / 连击)** | **正向播放与级联倍速** | 初始点击为 $1\times$ 正放；连续按击依次升级为 $2\times \to 4\times \to 8\times \to 16\times$ 极速前推 |
| **`K`** | **瞬时急停 (Stop/Pause)** | 立即冻结播放头当前 PTS；重置当前倍速计数器为 $1\times$ |
| **`J` (单按 / 连击)** | **反向倒放与级联倍速** | 初始点击为 $-1\times$ 倒放；连续按击依次升级为 $-2\times \to -4\times \to -8\times \to -16\times$ 极速倒退 |
| **`K + L` (按住 K 单击 L)** | **逐帧正向微调 (Step Forward)** | 单次步进当前时间基准下的精确 1 帧画面并暂停 |
| **`K + J` (按住 K 单击 J)** | **逐帧反向微调 (Step Back)** | 单次倒退当前时间基准下的精确 1 帧画面并暂停 |
| **`Space` (空格键)** | **启停切换 (Play / Pause)** | 在暂停与 $1\times$ 正放之间单键快速切换 |

#### 2.5.3 鼠标手势与修饰键行为矩阵 (Modifier Keys Matrix)

| 鼠标 + 修饰键组合 | 作用目标 | 核心交互行为 | 架构底层约束 |
| :--- | :--- | :--- | :--- |
| **`Alt + 鼠标左键拖拽`** | 任意 Clip 切片 | **原地复制副本 (Duplicate)** | 鼠标释放瞬间向命令栈提交 `DuplicateClipCommand`，源片段与新片段相互独立 |
| **`Alt + 鼠标滚轮`** | 时间轴工作区 | **以鼠标光标为中心横向缩放 (Zoom)** | 缩放锚点严格锁定在鼠标悬停处的 `RationalTime`，左右两侧按比例向外或向内缩放 |
| **`Ctrl + 鼠标滚轮`** | 时间轴工作区 | **时间轴水平平移 (Horizontal Pan)** | 左右平移可见时间窗口，单次滚轮步进为当前视口时长的 $5\%$ |
| **`Shift + 鼠标滚轮`** | 时间轴工作区 | **轨道高度垂直滚动 (Vertical Scroll)**| 上下滚动多轨层级，越过可见轨道边界时动态加载 |
| **`S` (单键切换)** | 全局时间轴 | **磁性格网吸附 (Snap) 开关** | 切换全局磁吸状态，开启时片段边缘、播放头与切点自动吸附 |
| **拖拽中按住 `Shift`** | 移动切片 / 标尺 | **临时反转磁吸状态 (Temp Snap Toggle)** | 若全局 Snap 开启，按住 Shift 临时禁用磁吸；反之临时强制开启磁吸 |
| **`Shift + Delete`** | 选中切片 | **波纹删除 (Ripple Delete)** | 剔除目标片段，后方素材自动向左贴合，时间轴总时长收缩 |
| **`Ctrl + K`** | 全轨道 | **当前时间播放头切刀 (Add Edit)** | 在当前播放头 PTS 处将所有未锁定的激活轨道一次性切断 |

#### 2.5.4 多轨时间轴序列 (Timeline Canvas)
- **顶部标尺与控制行**：
  - 当前时间码（`00:00:00:00`，等宽大字号）。
  - `Snap` 磁吸吸附开关（磁铁图标，快捷键 `S`）。
  - 链接选择开关（音视频关联）。
  - 时间刻度标尺（`00:00:00:00`, `00:00:01:00`, `00:00:02:00` ...），拖动标尺可直接拖拽播放指针。
- **轨道层级与轨道头 (Track Headers) 详述**：
  1. **字幕与台词轨 (`C1`)**：
     - 锁轨开关、眼球可见性开关、`Subtitle` 标签。
     - 放置由 `faster-whisper 1.2.1` 自动转写并断句的字幕片段。
     - 片段采用金橙色背景（`#3D3418`），直接显示台词文字（如“1973年”、“美国的加油站外”、“排起了长队”）。
  2. **高阶视频轨 (`V3` / `V2`)**：
     - 锁轨、可见性。
     - 放置 **HyperFrames 动效渲染层**（角标、花字、数据图表动画）及 画中画 / 贴图素材。
  3. **主视频轨 (`V1`)**：
     - 源修补指示灯（`V1` 激活高亮为 `#76B900`）、锁轨、眼球、`Video 1` 标签。
     - 放置原始拍摄素材切片，片段采用深青色底（`#1B334B`），头部与尾部带视频帧缩略图，右侧带 `fx` 激活徽章。
  4. **主口播音频轨 (`A1`)**：
     - 源修补指示灯（`A1` 激活高亮为 `#76B900`）、锁轨、`M` (静音)、`S` (独奏)、麦克风录音键、`Audio 1` 标签。
     - 放置主口播音频，片段采用暗松绿色底（`#17382B`），中间绘制鲜绿色高精细波形（`#76B900`）。
     - 音频块中间贯穿一条细白增益线，支持用钢笔工具添加音量渐变关键帧。
     - **口播待剔除提示**：Agent 探测到的停顿气口和重说片段以半透明红色覆盖条（`#4A1515`）标出，用户可一键执行波纹切除。
  5. **环境与 BGM 音频轨 (`A2` / `A3`)**：
     - 锁轨、`M`、`S`、麦克风。放置背景音乐、音效，与主口播自动进行避让（Ducking）。
- **时间轴底部视窗缩放与滚动条**：
  - 左右两端带有圆形把手（Handles），拖动可横向缩放时间轴刻度（从查看微秒级单帧到纵览数小时全貌）。

#### 2.5.5 主音频电平表 (Master Audio Meters)
- **宽度**：`24px`，竖直固定在时间轴右侧。
- **规格**：立体声双通道（左声道 L / 右声道 R），垂直电平柱实时跳动。
- **刻度**：从顶部 `0 dB` 往下分布：`-6`, `-12`, `-18`, `-24`, `-30`, `-36`, `-42`, `-48`, `-54 dB`。
- **颜色梯级**：正常区为深绿，高于 `-6 dB` 渐变为黄色，超过 `0 dB` 变红并保持过载 Clip 警告指示灯。

### 2.6 效果控件面板 (Effect Controls) [右下区域]
- **面板职责**：针对时间轴上当前选中的任何音视频/动效 Clip 进行全参数属性调节与曲线动画打点。
- **顶部 Tab**：`Effect Controls`，并列展示选中的素材源名称。
- **参数控制树 (Parameters Tree)**：
  - **`Video`**
    - `fx Motion` (运动)
      - `Position`：坐标参数（如 `1876.9`, `1436.7`，支持滚轮/拖拽即时调节）。
      - `Scale`：缩放比例（如 `611.4%`），带 `Uniform Scale` 等比勾选框。
      - `Rotation`：旋转角度（`0.0°`）。
      - `Anchor Point`：锚点坐标（`320.0`, `240.0`）。
      - `Anti-flicker Filter`：抗闪烁过滤。
      - `Crop`：左/上/右/下裁切百分比。
    - `fx Opacity` (不透明度)
      - 蒙版形状工具快捷键（圆形、矩形、自由钢笔）。
      - `Opacity`：百分比（`100.0%`）。
      - `Blend Mode`：混合模式下拉框（Normal, Screen, Multiply 等）。
    - `fx Time Remapping` (时间重映射 / 变速曲线)
    - ⭐ **`fx HyperFrames Params`**（若选中动效切片时激活）：
      - 自动绑定该 Web 动效组件的参数列表（如标题文案、动态数字、进出场时间）。
- **右侧关键帧迷你时间轴 (Mini Keyframe Timeline)**：
  - 缩略对应当前片段的持续时间区间，可在参数旁点击秒表图标打上菱形关键帧（`Keyframe Diamond`），并拖拽贝塞尔曲线手柄调节加减速曲线。

## 3. 与 ClipFlow 整体系统架构与设计体系的融合

1. **圆角曲率彻底替换为 Windows 11 Fluent 规范**：
   - PR 原生界面中各面板为传统的 0-1px 硬直角边框；在 ClipFlow 中，六大核心面板的外框全面采用 **Win 11 `8px` 舒适曲率**，按钮与输入控件采用 **`4px`**，时间轴片段采用 **`3px`**，避免视觉割裂感。
2. **NVIDIA 标志性电能绿 (`#76B900`) 全面替代 Adobe 亮蓝**：
   - 将原图中的高亮蓝色源修补块（`V1`, `A1`）、时间轴反向五边形播放指针、激活选中框全面替换为 **NVIDIA Green (`#76B900`)** 与 **Electric Lime (`#BFF230`)**，与整套工控设计体系保持一致。
3. **全局公用时间线无缝接合**：
   - 剪辑工作台下部的【2.5 核心多轨公用时间线】在用户点击底部 Dock 栏切换到 `Agent`、`动画`、`声音`、`图片` 或 `导出` 页面时，其播放指针坐标、多轨片段数据与缩放视口在内存中绝对常驻，仅上部视窗按需切换为对应工作流界面。

## 4. 即时模式时间轴渲染性能优化规范 (egui Immediate Mode Optimization)

为了彻底解决 `egui 0.36` 即时模式在多轨长视频（几千个碎片化口播切片 + 海量声波采样）下每帧重绘导致的 CPU 算力飙升隐患，`clipflow-ui` 模块必须严格执行以下三项性能规约：

### 4.1 正交二维视口剪裁与纵向轨道虚拟化 (2D Orthogonal Viewport Culling)
- **物理拓扑**：时间轴为二维正交平面——X 轴为单调递增时间戳，Y 轴为动态高度轨道容器（普通 V 轨 64px、音频展开 120px、折叠轨 32px）。
- **两级正交裁剪流水线**：
  1. **Y 轴轨道垂直二分粗筛**：维护轨道顶部 Y 坐标前缀和数组 `track_y_starts: Vec<f32>`。视口垂直范围为 $[Y_{\text{min}}, Y_{\text{max}}]$，附加 $64\text{px}$（约 1 条缓冲轨）扩展裕量。利用 `partition_point` 二分快速定位可见轨道区间 $[i_{\text{start}}, i_{\text{end}})$，视口外轨道连轨道头控件与背景网格均 100% 跳过计算。
  2. **X 轴时间单调区间二分切片筛选**：在可见轨道内，各 Clip 严格按 `timeline_range.start` 升序排列。附加 $120\text{px}$ 对应的时间裕量，通过二分查找确定首个与视口相交的片段索引：
  ```rust
  // 1. 纵向跳过不可见轨道:
  for track_idx in visible_tracks {
      let track = &sequence.tracks[track_idx];
      let clips = track.clips();
      
      // 2. 横向二分定位首个可见切片:
      let start_idx = clips.partition_point(|clip| clip.timeline_range.end_exclusive() <= vis_start_with_margin);
      for clip in &clips[start_idx..] {
          if clip.timeline_range.start >= vis_end_with_margin {
              break; // 超出视口右边界，立即终止横向遍历
          }
          render_clip(ui, track_idx, clip, &timeline_viewport);
      }
  }
  ```
- **收益**：遍历复杂度由 $O(M \times N)$ 降至 $O(\log M + \log N + K)$（$K$ 为屏幕内可见总切片数，通常 $\le 80$），单帧二维粗筛耗时锁定在 $\le 0.04\text{ms}$。

### 4.2 音频波形 LOD 金字塔与网格保留 (Waveform LOD & Mesh Retaining)
- **多级细节（LOD）选择**：根据当前时间轴缩放比例（`pixels_per_second`），自适应从 `.peak` 文件读取对应精度（详见 [`docs/media-pipeline-spec.md` 第 4.4 节](file:///d:/Work/Dev/ClipFlow/docs/media-pipeline-spec.md)），严禁高缩放全景视角下绘制微秒级密度的波形。
- **Mesh 顶点复用**：音频波形绘制统一生成为单个 `egui::Mesh`（三角形条带）；在视口未发生平移和缩放、仅播放指针前进时，波形 `Shape::Mesh` 保持完全复用，禁止每一帧重新进行三角形顶点计算。

### 4.3 脏区与按需重绘驱动 (Selective Repaint)
- **静止状态零开销**：视频暂停且无鼠标悬停、无拖拽时，界面主循环禁止盲目调用 `ctx.request_repaint()`，系统挂起于 Windows OS 消息队列，渲染帧率降为 0 FPS，CPU 占用降为 0.0%（详见 [`docs/architecture.md` 第 4.3 节](file:///d:/Work/Dev/ClipFlow/docs/architecture.md) `RepaintScheduler` 规范）。
- **播放状态局部化**：播放期间仅以 60 FPS 节拍器触发播放指针（Playhead）与监视器贴图的重绘，轨道底板与未改变的片段静态外框不参与重新栅格化。

### 4.4 C1 字幕轨文本排版 Galley 缓存与字形管线 (Subtitle Galley Cache)
- **字形与几何解耦**：时间轴横向缩放改变的是切片像素外框宽度，文字字号与成型度量（Text Shaping）保持不变。严禁在缩放或重绘时对未修改文字重复调用 `ui.fonts().layout()`。
- **两级排版缓存机制**：
  1. 维护固定容量为 **1024 槽位** 的全局 LRU 缓存池 `SubtitleGalleyCache`，以 `(TextString, FontSize, StyleFlag)` 为复合索引键；
  2. 命中缓存直接获取已生成的 `Arc<egui::Galley>` 句柄并提交 GPU 顶点流，配合 `painter.with_clip_rect(clip_rect)` 硬件裁切溢出文字；
  3. 缓存命中率红线锁定在 $\ge 99\%$，全屏 60 个词级切片排版耗时从 $2.5\text{ms}$ 骤降至 $\le 0.05\text{ms}$。

### 4.5 高密度关键帧微型手柄交互与拖拽锁定状态机 (Keyframe Drag Lock)
- **视觉与判定解耦**：音频音量包络线与动效轨道的菱形手柄视觉外径严格保持 **$6\times 6\text{px}$**，逻辑交互判定框（Hitbox）向外等距扩展为 **$14\times 14\text{px}$**。相邻手柄判定区重叠时，以鼠标指针到关键帧时间戳的欧式距离就近吸附。
- **全局独占拖拽捕获状态机 (`DragLockContext`)**：
  1. 鼠标在判定区按下（`pointer.primary_down()`）瞬间，全局锁定该手柄唯一标识 `KeyframeHandleId`；
  2. 拖拽期间激活全屏幕捕获，彻底屏蔽相邻关键帧的 Hover/Click 抢占，仅更新内存瞬态位移预览；
  3. 鼠标释放（`pointer.primary_released()`）时，计算起止差量，向命令栈打包提交**单次原子化 `ModifyKeyframeCommand`**，杜绝撤销事务栈泛洪。

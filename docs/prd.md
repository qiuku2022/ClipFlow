# 产品与需求规格 (PRD)

## 1. 产品定位与特色

- **产品名称**：ClipFlow
- **核心定位**：Windows 端以 **剪辑 Agent（导演级 AI）** 为核心的智能桌面视频制作软件。
- **差异化特色**：
  - **Agent 即导演**：Agent 不仅是单点辅助工具，而是承担“导演”职责，负责整篇视频的剪辑规划方案设计（脚本理解、节奏把控、分镜挑选、花字与动效规约）并自动化驱动时间轴执行。
  - **口播智能剪辑**：根据音频波形与 ASR 文本，自动识别并剔除气口、停顿、语气词及错句重说，实现基于文本的无感粗剪。
  - **自动整理字幕**：高精度转写、标点智能断句与时间轴对齐，支持自动纠错与词级高亮。
  - **继承 HyperFrames 动效体系**：引入 HeyGen 开源的“Agent-Native”框架 HyperFrames，允许 Agent 与用户以代码（HTML/CSS/JS/GSAP/Lottie）生成可寻址、逐帧确定性渲染的动画、角标、花字及图表包装。

## 2. 界面与交互范式

整体界面采用**专业工作流分页**结构，底部借鉴 **达芬奇 (DaVinci Resolve) Dock 栏分页切换模式**（仅参考其分页栏交互模式与位置，不采用其内页设计），并确立**“全局贯穿式公用时间线”**为核心骨架：

```
+---------------------------------------------------------------------------------+
|                                                                                 |
|                        上层页面专属工作区 (由底部 Dock 栏切换)                    |
|             (如: Agent 导演对话 / PR 双监视器 / HyperFrames 代码预览等)          |
|                                                                                 |
+---------------------------------------------------------------------------------+
|                     【全局公用时间线】(Global Shared Timeline)                    |
|      所有页面公用同一条时间线：多轨数据、播放指针位置、片段与播放状态全局无缝延续  |
+---------------------------------------------------------------------------------+
| [ Agent ] | [ 剪辑 ] | [ 动画 ] | [ 声音 ] | [ 图片 ] | [ 导出 ]  <-- 达芬奇式底部 Dock |
+---------------------------------------------------------------------------------+
```

### 2.1 全局公用时间线规范 (Shared Timeline Core)
- **单一事实来源 (SSOT)**：整篇视频的时间轴序列（视频轨、音频轨、字幕轨、动效轨）是全局唯一底层数据结构，任何页面对时间轴的改动（如 Agent 自动切片、剪辑页手动波纹剪切、动画页插入角标）实时反映在所有视图中。
- **播放状态无缝漫游**：用户在任何页面移动播放指针 (Playhead)、启停播放、缩放时间轴，切换到其他任何页面时保持原位与当前帧画面，绝不重置。
- **各页面与公用时间线的协同**：
  - **在 `Agent` 页**：时间线上实时可视化呈现 Agent “导演”规划的切分点、镜头分类、待剔除口播气口（红显标注），方案确认后片段瞬时自动对齐重组。
  - **在 `剪辑` 页**：时间线进入完全对齐 PR 的专业多轨编辑模式，激活剃刀工具、滑动/滑移、关键帧手柄与磁吸吸附。
  - **在 `动画` 页**：时间线自动锚定 HyperFrames 动效图层，播放指针所在位置直接驱动 HTML 动效帧的精准预览。
  - **在 `声音` 页**：时间线纵向拉伸音频轨道，高精度显示音频能量波形与音量包络线。
  - **在 `图片` 页**：时间线直接呈现静态图片与 B-Roll 的跨轨时间长度，支持素材一键拖拽覆盖。
  - **在 `导出` 页**：时间线自动切换为出入点 (In/Out Work Area) 渲染标记范围预览。

## 3. 核心功能特性矩阵 (Features)

### 3.1 导演级 Agent 规划与执行
- **全局剪辑方案生成**：用户输入主题或初始长素材，Agent 输出结构化剪辑方案（包含切分点、画面焦点、BGM 选型、动画包装建议）。
- **文本驱动剪辑 (Text-based Editing)**：时间轴与转写文本深度双向联动，剪掉文本即可同步切除对应音视频片段。
- **方案一键落地**：Agent 规划直接转换为 Rust 内部时间轴数据结构（Track/Clip/Transition/Effect），秒级呈现在 PR 剪辑界面。

### 3.2 自动口播粗剪
- **多维度噪音/气口分析**：结合 FFmpeg `silencedetect` 与音频能量阈值。
- **语病与重说消除**：大模型或 NLP 启发式分析 Whisper 转写文本，识别连续重复词、倒装重读句、语气助词（“嗯”、“啊”、“这个”），自动生成修剪标记。

### 3.3 自动整理字幕
- 基于 `faster-whisper` 1.2.1 (`large-v2` 模型) 本地推理。
- 词级时间戳（Word-level Timestamps）精准对齐。
- 标点自动规范化、断句断行优化（单行字符限制）。

### 3.4 HyperFrames 动效集成
- **组件库预置**：下三分之一角标（Lower Thirds）、章节标题卡、数据动态折线图/柱状图、设备样机外框。
- **Agent 生成动效**：Agent 可直接编写或修改 HTML/CSS，HyperFrames 逐帧生成透明通道视频叠加轨。

## 4. 运行环境与性能指标
- **操作系统**：Windows 10/11 64-bit。
- **图形渲染**：依托 `wgpu 30.0` 硬件加速与 `egui 0.36` 即时渲染，UI 保持 60+ FPS 流畅渲染，时间轴拖拽低延迟。
- **AI 运行时**：GPU 模式显存占用受控，无 CUDA 环境时 CPU 兜底仍可保持批处理高效运转。
